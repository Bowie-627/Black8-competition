# 公司中式黑八挑战赛

这是一个零依赖、可在公司局域网运行的赛事网页。所有报名、比分和管理操作都会保存到 `data/tournament.json`；只要同事访问同一台运行服务器的电脑，即可共享数据。

## 启动

1. 在本目录打开 PowerShell。
2. 执行 `npm start`。
3. 本机访问 `http://localhost:3000`。同事手机访问 `http://电脑局域网IP:3000`。
4. Windows 首次询问防火墙时，请允许 Node.js 使用“专用网络”。

默认管理 PIN 是 `1234`。请在“管理”页的赛事设置中及时修改。

## 已实现规则

- 8 人严格限额，ID 不可重复；头像可选。
- 8 人随机分为 A/B 两组，每组循环赛；每场 3 局 2 胜。
- 胜场、净胜分、总得分排序；前两名交叉进入半决赛。
- 半决赛和决赛为 5 局 3 胜。单局赢家固定记 8 分，输家录入 0–7 分。
- 支持成绩撤销、赛程重置、全量重置及管理日志。

数据文件请勿在服务运行时手动编辑；如需备份，停止服务后复制 `data/tournament.json` 即可。

## Railway 部署

在 Railway 为服务添加 Volume 时，将挂载路径设为 `/data`，并在 Variables 新增 `DATA_DIR=/data`。首次启动时，程序会自动将仓库里的 `data/tournament.json` 写入数据盘；之后的报名和比分都会保存在数据盘中。
